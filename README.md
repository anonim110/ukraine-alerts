# Тривоги України

Мінімалістичний сайт з картою активних повітряних тривог в Україні.

## Що є

- карта областей України;
- окреме відображення тривоги на рівні області та тривоги в окремих районах;
- час від початку активної події;
- пошук області;
- автооновлення кожні 30 секунд;
- адаптивна мобільна версія;
- опційний звуковий сигнал при появі нової тривоги.

## Дані

Сайт використовує публічний API Tryvoha.online (`https://tryvoha.online/api/v1/alerts`).
Реєстрація та API-ключ не потрібні. Відповідно до умов API на сайті збережено видиму атрибуцію джерела.

Tryvoha.online — інформаційний сервіс на основі відкритих джерел. Для рішень щодо особистої безпеки слід користуватися офіційними каналами та вказівками органів влади.

## Render

Проєкт є звичайним статичним HTML/CSS/JS сайтом і не потребує сервера або бази даних.

- Build command: `echo "Static site"`
- Publish directory: `public`

У репозиторії також є `render.yaml`.
