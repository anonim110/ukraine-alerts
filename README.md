# Тривоги України

Мінімалістичний сайт з картою активних повітряних тривог в Україні.

## Що є

- карта областей України;
- окреме відображення тривоги на рівні області та тривоги в окремих районах;
- час від початку активної події;
- пошук області;
- автооновлення кожні 30 секунд;
- адаптивна мобільна версія;
- опційний звуковий сигнал при появі нової тривоги.

## Дані

Сайт використовує API [alerts.in.ua](https://alerts.in.ua/) (`https://api.alerts.in.ua/v1/alerts/active.json`).
Показуються тривоги по областях, районах, громадах і містах, а також інші типи загроз
(артобстріл, вуличні бої, хімічна та радіаційна загроза).

Токен API не потрапляє в браузер: його використовує невеликий сервер `server.js`,
який проксіює запити через `/api/alerts` і кешує відповідь на 15 секунд (ліміти API).

Для рішень щодо особистої безпеки слід користуватися офіційними каналами та вказівками органів влади.

## Локальний запуск

Потрібен Node.js 18+. Залежностей немає.

```bash
ALERTS_IN_UA_TOKEN=ваш_токен npm start
# http://localhost:3000
```

## Render

- Тип: Web Service, runtime Node
- Start command: `node server.js`
- Змінна оточення: `ALERTS_IN_UA_TOKEN` — токен з alerts.in.ua (задати в Render → Environment, **не комітити в репозиторій**)

У репозиторії також є `render.yaml`.
